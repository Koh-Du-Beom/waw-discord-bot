# 초기 기술 제약사항과 요구사항 추적표

- 상태: Research
- 작성일: 2026-07-20
- 마지막 갱신일: 2026-07-31
- 범위: 제품 정책, 운영·보안 정책과 프로젝트 표준에서 기술 조사 입력을 추출
- 비범위: 기술 선택, 추천안 확정, ADR 작성·승인, Spike 실행, 제품 코드 구현

## 조사 원칙

- 아래 요구사항은 후보를 배제하거나 검증하는 기준이지 특정 기술의 근거가 아니다.
- `MUST`는 정책상 필수, `SHOULD`는 설계 시 비교·검토가 필요한 요구사항이다.
- 사실, 가정, 소유자 결정과 조사 결과를 분리한다.
- 후보 비교는 공식 문서와 1차 자료를 우선하고, 문서로 확인할 수 없는 항목만 폐기 가능한 Spike로 검증한다.
- 요구사항 ID는 이후 연구, Spike, ADR, 계획과 테스트에서 그대로 참조한다. 의미가 달라지면 기존 ID를 재사용하지 않고 새 ID를 추가한다.

## 핵심 제약

1. Discord Gateway를 사용하는 봇은 장시간 연결, 재연결과 단일 활성 실행을 다뤄야 한다.
2. 대시보드의 유일한 확정 운영 호스트명은 `https://waw.dubeom.com`이다.
3. 시간 범위 요약은 범위 전체를 처리하거나 명시적으로 실패해야 하며 조용한 누락은 허용되지 않는다.
4. Discord 메시지 원문과 인증 비밀은 로그나 영구 저장소에 남길 수 없다.
5. 몰랭 판정은 Riot 게임 상태와 Discord Go Live를 사용하며 Twitch는 판정 근거가 아니다.
6. 데이터 계층에는 원자성, 참조 무결성, 버전형 마이그레이션, 백업과 실제 복구 검증이 필요하다.
7. 웹과 봇을 분리하면 통신 경계에 상호 인증, 멱등성, 타임아웃과 안전한 실패가 필요하다.
8. 아직 확정된 언어, 런타임, SDK, 프레임워크, 저장소, 호스팅 또는 외부 데이터 공급자는 없다.
9. KBO 운영 데이터는 Discord·대시보드 표시, 자동 접근, 저장과 필요한 보존
   권리를 서면으로 확인한 공급 경로에서만 받을 수 있다.
10. 가상 크레딧은 현실 가치가 없고 구매·판매·현금화·양도·교환할 수 없다.

## 추적성 공백과 충돌

- 현재 문서 사이에 직접적인 정책 충돌은 발견되지 않았다.
- 대시보드 로그인은 Discord OAuth만 허용한다. OAuth 로그인 성공 자체는 인가가 아니며, 허용 guild와 현재 역할을 서버에서 별도로 검증한다.
- 시간 범위 전체 요약은 요청 시작 시점에 명령 위치에서 봇이 접근할 수 있는 메시지를 기준으로 한다. 수집 중 삭제·편집·권한 변경으로 완전성을 보장할 수 없으면 부분 결과 없이 전체 요청을 실패시킨다.
- 원문은 프로젝트 DB·파일·로그에 영구 저장하지 않는다. 학습에 사용되지 않는 유료 API 설정에서 공급자의 제한적인 안전성 보존은 고지를 전제로 허용하며, 별도 상태 저장은 끄고 ZDR이 현실적으로 가능하면 우선 검토한다.
- `FUN-007`~`FUN-009`는 2026-07-27 제품 결정으로 제거된 이력 ID이며 재사용하지
  않는다. KBO는 2026-07-31 소유자 결정으로 제품 범위에 다시 포함했고 새
  `FUN-021`~`FUN-031`으로 추적한다.
- Riot RSO 승인 실패 시 관리자 승인 연결을 허용하되 공식 검증과 구분한다. 5분 감지가 검증되지 않으면 임의로 목표를 완화하지 않고 수동 확인을 유지한 채 소유자가 다시 결정한다.
- 대시보드의 “복구 절차 안내”와 위험 수준별 권한은 있으나 웹에서 실제 복구를 실행해야 한다는 요구는 없다. 초기 범위에 원격 복구 실행을 넣지 않는다.

## 가정과 미확인 사항

- 단일 개인 Discord 서버용 소규모 시스템이며 첫해 월 명령은 최대 10,000회로 검증한다. 예상 사용자 수, 메시지량과 동시 게임 수는 미확인이다.
- 현재 저장소에는 운영 중인 제품 코드, Accepted ADR과 구현 계획이 있다.
  KBO 전용 제품 코드, migration, runtime dependency와 credential은 아직 없다.
- `waw.dubeom.com`의 기존 운영 경계는 유지하며 KBO 때문에 별도 production
  hostname이나 public 관리 API를 추가하지 않는다.
- KBO 30분 지연 기준은 새 명세에서 되살리지 않았으며 과거 결정 기록으로만
  남긴다. 새 데이터 신선도 임계값은 공급자 계약·실측 후 별도 결정한다.
- 외부 API 계약, 가격과 실제 KBO coverage는 아직 확정하지 않았다. 서면 권리와
  공급 조건을 확인하기 전에는 운영 데이터 수집과 베팅을 활성화하지 않는다.
- 베팅 한도와 시즌 랭킹·관리자 조정 반영은 `OWN-044`~`OWN-045`, 공개 전
  법률·등급 gate는 `OWN-047`, 최소 서버 탈퇴 처리는 `OWN-048`로 결정됐다.
  사용자용 베팅 탈퇴·복구를 포함했던 `OWN-046`은 대체됐다.
- 연구 중 설치나 배포는 하지 않는다. 문서만으로 불충분할 때 별도 승인된 Spike가 최소한의 폐기 가능한 자원을 사용할 수 있다.
- 자가 host 확인 중 관측한 실제 공인 IP는 문서와 로그에 보존하지 않는다. 교육장 회선은 네트워크 관리자 서면 승인 전 운영 경로에서 제외한다.
