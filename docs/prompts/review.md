# Review

Review the requested change against policies, Accepted ADRs, implementation plans, and standards.

Prioritize:

1. Incorrect behavior
2. Security or privacy flaws
3. Data loss or corruption
4. Authorization errors
5. Duplicate processing and concurrency
6. Failure and recovery behavior
7. Missing tests
8. Documentation drift
9. Maintainability

Provide concrete findings with file and location references. Distinguish blocking issues, non-blocking issues, and questions. Do not approve based only on style.
