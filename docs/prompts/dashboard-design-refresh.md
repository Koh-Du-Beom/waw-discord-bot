# WAW dashboard design refresh

`waw.dubeom.com` 관리 대시보드의 UX/UI를 이 브랜치에서 전면 개선한다.

## 제품 맥락

- 소규모 친구 Discord 커뮤니티를 위한 비공개 운영 서비스다.
- 핵심 브랜드와 명령어 `/몰랭검거`는 반드시 유지한다.
- 장난스럽고 친근하지만 유치하거나 공격적으로 보이면 안 된다.
- 일반적인 SaaS 관리자 템플릿처럼 보이지 않게 한다.
- 한국어를 기본 언어로 사용한다.
- canonical production domain은 `https://waw.dubeom.com`이다.
- 자동으로 감지된 Riot/Go Live 불일치는 확정 위반이 아니라 관리자가 검토할 참고 신호다.

## 작업 목표

1. 현재 화면, 컴포넌트, 정보 구조, 접근성, 반응형 상태를 먼저 감사한다.
2. 기존 기능, API, 인증, 권한, 라우팅 계약을 변경하지 않고 시각 체계와 UX를 개선한다.
3. 현실적인 디자인 방향 2~3개를 비교하고 근거를 기록한 뒤 가장 적합한 하나를 선택한다.
4. 대시보드 홈, Riot 연결 요청 관리, 몰랭 관측/스택, 감사 및 운영 상태를 일관된 정보 구조로 정리한다.
5. `정상`, `확인 필요`, `불일치`, `알 수 없음`, `정정됨`을 색상뿐 아니라 아이콘과 텍스트로 구분한다.
6. 자동 불일치를 위반 확정처럼 표현하지 않는다.
7. PUUID, Discord 식별자, 토큰, 세션 및 기타 비밀을 화면, 로그, 테스트 결과에 노출하지 않는다.
8. 모바일과 데스크톱을 지원하고 WCAG AA 수준의 대비, 키보드 탐색, 명확한 포커스 표시를 검증한다.
9. 기존 의존성과 프로젝트 패턴을 우선 사용하며 불필요한 UI 라이브러리를 추가하지 않는다.
10. 실제 브라우저 검증은 Orca 내장 브라우저에서만 수행한다.

## 시각 방향

- Discord 친구 모임의 비밀 작전실 같은 분위기
- 어두운 네이비 또는 먹색 기반과 절제된 포인트 컬러
- 카드 남발보다 명확한 계층과 밀도 있는 운영 화면
- `/몰랭검거`를 기억에 남는 핵심 브랜드로 표현
- 재미있는 문구는 보조적으로만 사용하고 중요한 운영 결과는 명확하게 작성
- 과도한 글로우, 그라디언트, 유리 효과, 거대한 숫자 카드, 흔한 AI 생성 랜딩페이지 스타일은 피한다.

## 필수 절차

1. `AGENTS.md`에 지정된 필수 문서를 순서대로 읽는다.
2. 기존 사용자 변경을 보존한다.
3. 구현 전에 현재 UI 감사 결과와 관찰 가능한 성공 기준을 작성한다.
4. 중요한 디자인 결정이 Accepted ADR이나 제품 정책과 충돌하면 구현 전에 보고한다.
5. 첫 단계에서는 production 코드를 변경하지 않고 현재 화면 감사와 2~3개 디자인 방향의 와이어프레임 또는 정적 프로토타입을 만든 뒤 검토를 요청한다.
6. 방향이 승인된 후 작은 단위로 구현한다.
7. `typecheck`, 관련 테스트, browser accessibility check를 실행한다.
8. 가능하면 변경 전후 스크린샷을 남긴다.
9. production 배포나 `main` 병합은 하지 않는다.

## 완료 보고

- 변경 파일
- 디자인 결정과 근거
- 기존 동작 중 보존한 계약
- 실행한 명령과 테스트
- 접근성 및 반응형 검증 결과
- 남은 문제
- `main`으로 가져올 때의 권장 통합 순서
