# Start Project

Read `AGENTS.md` and all mandatory documents.

Work in research-only mode. Do not create production application code, choose a final stack, install production dependencies, or deploy anything.

1. Inspect the repository.
2. Extract functional, non-functional, operational, security, privacy, data, backup, recovery, and deployment requirements.
3. Assign stable requirement IDs and create a traceability table.
4. Identify contradictions, owner decisions, assumptions, and research questions.
5. Create `docs/research/technical-constraints.md`.
6. Create `docs/research/technology-options/initial-decision-map.md`.
7. Propose an evidence-based research sequence.
8. Create no Accepted ADRs.
9. Update `PROJECT_STATUS.md`.
10. Stop after the research plan is complete.

Report changed files, key constraints, owner decisions, research order, commands run, and the exact next prompt.
