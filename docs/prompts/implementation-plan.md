# Implementation Plan

Read `AGENTS.md` and use only Accepted ADRs as architectural authority.

Create a plan using `docs/implementation/TEMPLATE.md`.

1. Define goal, scope, and non-goals.
2. Map work to requirements and ADRs.
3. Split work into small independently verifiable tasks.
4. Name expected files and test types.
5. Include permissions, failures, external APIs, data migration, observability, backups, and rollback.
6. Identify dependencies and blockers.
7. Define completion criteria.
8. Do not implement code.
9. Keep the plan Draft until owner approval.

Report the plan path, unresolved issues, review checklist, and exact approval prompt.
