# Bug Fix

Read `AGENTS.md`, relevant policies, ADRs, implementation plans, and recent changes.

1. Reproduce the bug.
2. Determine impact and likely cause.
3. Add a regression test when feasible.
4. Fix the smallest root cause, not only the visible symptom.
5. Test failure, permission, timeout, duplicate, and recovery paths as relevant.
6. Check whether policy, ADR, migration, monitoring, or runbook updates are required.
7. Avoid unrelated refactoring.

Report reproduction, root cause, changed files, tests, residual risk, and the exact next prompt.
